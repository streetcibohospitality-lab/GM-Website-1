# GM Command Center v6.3 — Glassmorphism Visual Pass

This pass changes presentation only. No business logic, database schema, authorization, MFA, owner registry, API routes, or production gates were modified.

## Visual changes
- Dark frosted-glass shell with red/teal ambient light only.
- Translucent navigation rail and sticky topbar with stronger separation.
- Glass KPI, report, operational, security, maintenance, people, task and document surfaces.
- Consistent luminous borders, restrained highlights, blur, shadows and hover elevation.
- Glass inputs, command palette, drawers and record modals.
- Light/cream panels converted from opaque paper to smoked light glass.
- Responsive fallbacks and no-backdrop-filter fallback retained.
- Existing accessibility contrast and semantic red/teal status cues preserved.

## Scope
CSS-only visual change in `app/globals.css` plus this handoff note.
