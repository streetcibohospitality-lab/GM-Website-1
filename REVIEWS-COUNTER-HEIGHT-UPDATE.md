# Reviews + Counter 08 Height Update

The shared Diner Noticeboard + Counter 08 scene has been compressed to roughly half its previous desktop height while preserving the same visual language and functionality.

Changes apply on desktop/laptop widths above 1050px:
- reduced section top/bottom padding
- reduced noticeboard and paper padding
- smaller but still readable review typography
- compact review navigation
- reduced Counter 08 headline scale and internal spacing
- compact order buttons and bell
- thinner checker bridge
- smaller Hungry Yet diner sign and CTAs

No review, navigation, order link, bell interaction, or Hungry Yet CTA was removed.
