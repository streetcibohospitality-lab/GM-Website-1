# Retro Ambient Detail Update

This build adds restrained retro detail to negative space without changing the website's core layout.

Added:
- atomic diner starbursts with a slow single "wink"
- low-opacity rubber stamp marks
- tiny halftone clusters
- chrome photo-frame hardware and slow glints
- Route 63 roadside marker in Locations with a one-time settling motion
- thin chrome counter rails between major scenes
- subtle diner-booth stitching on selected dark/red sections
- the same decorative language carried into Menu and Franchise hero areas

Grub Time:
- the analog clock now runs on real India Standard Time using `Asia/Kolkata`
- a live digital IST readout updates every second
- the clock remains CSS/DOM based; no fake animation or prerecorded time

Motion remains intentionally sparse:
- one star wink approximately every 7 seconds
- frame glints around every 9–10 seconds
- rail glints around every 10–11 seconds
- Route 63 settles once when Locations enters view
- reduced-motion preferences disable ambient animation

Implementation note:
- The existing “What Should I Order?” machine remains generated by `interactive-diner.js`; this patch does not alter its randomized menu logic.
