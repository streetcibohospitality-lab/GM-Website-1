# Compact Monkey Jukebox Update

The existing CSS-built jukebox was reduced from a maximum desktop width of 680px to 360px, which is approximately a 47% reduction in linear width and visually reads as the requested ~50% smaller jukebox.

Nothing functional was removed:

- original CSS jukebox shell
- arch / lights / speaker / columns / base
- animated vinyl record
- coin slot and coin-drop animation
- Drop Coin button
- A1 Classic Rock selector
- A2 / B1 / B2 coming-soon selectors
- selection note
- Mixcloud player
- user-controlled audio behavior
- responsive/mobile behavior
- reduced-motion behavior already present in the project

The player panel is proportionally wider within the smaller shell and the four selectors use a 2×2 layout so the controls remain readable instead of simply scaling every element down to unusable size.
