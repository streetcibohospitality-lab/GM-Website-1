# Order + Hungry Yet Combined Update

## What changed

The full-screen **Hungry Yet?** section has been removed as a separate page-height section.

Its content now lives inside the existing **Hot Grub. Few Taps.** order card, so the customer sees one compact conversion area instead of two consecutive pages communicating the same action.

The current Reviews + Order shared scene remains intact.

## Desktop layout

- Left: compact customer review noticeboard
- Right:
  - `HOT GRUB. FEW TAPS.`
  - Swiggy / Zomato ordering controls
  - existing order bell interaction
  - small checker transition
  - compact `HUNGRY YET?` diner sign
  - View Menu / Find A Diner controls

## Preserved features

- Review carousel and arrows
- Order On Swiggy
- Order On Zomato
- Chrome order bell / ORDER UP interaction
- Hungry Yet sign bulb animation
- View Menu
- Find A Diner
- Existing fonts, brand colors, grain, ticket buttons and diner styling
- Compact jukebox changes
- Random What Should I Order logic
- Previous Reviews + Order consolidation

## Responsive behavior

The right-hand order card remains one component on desktop. On tablet/mobile, its internal content stacks while keeping all buttons and interactions usable.

No functionality was removed; only redundant vertical space was removed.
