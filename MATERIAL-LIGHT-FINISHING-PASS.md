# Material + Light Finishing Pass

This pass intentionally avoids repeating the site's existing retro language
(stamps, atomic sparks, halftones, chrome rails, tickets, diner props, etc.).

It adds four different techniques:

1. **Hall of Fame — Formica tabletop**
   - subtle mint/cream diner surface
   - tiny material speckle
   - chrome table edge beneath the square gallery
   - photographs remain completely unobstructed

2. **Born in Manipal — diner-window / blind shadows**
   - large soft light/shadow projection over the cream negative space
   - extremely slow drift
   - content remains above the effect

3. **Locations — oversized cropped editorial typography**
   - very low-opacity KARNATAKA / DINERS 63 typography
   - fills excess width without adding another object or badge

4. **Jukebox — projected neon reflections**
   - red and teal ambient light on the wall
   - no visible additional neon sign
   - slow breathing only

Subpage continuity:
- Menu gets a restrained Formica surface behind the category area.
- Franchise gets a subtle diner-window light/shadow treatment.

No new JavaScript or animation library was added.
All motion is CSS-only and stops under `prefers-reduced-motion`.
